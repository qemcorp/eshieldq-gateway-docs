# Security Policy

## Reporting a vulnerability

Please report security issues to **support@quantumemotion.com**. Do not open a
public issue for a suspected vulnerability.

Include the affected version, what you observed, and the steps to reproduce it.
We will acknowledge your report and keep you informed while we investigate.

## Supported versions

This repository is published from tagged releases. Fixes are issued as new
releases; please upgrade to the latest version before reporting an issue.
